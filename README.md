# 🩸 VR Blood Collection Training Simulator

> 🚀 A Virtual Reality (VR)-based healthcare training application developed using **Unity**, **Blender**, and the **XR Interaction Toolkit** to simulate the blood collection procedure in an immersive virtual hospital environment.

---

## 📌 Project Overview

The **VR Blood Collection Training Simulator** is designed to provide a safe and interactive learning environment for practicing blood sample collection. The simulation recreates the workflow followed in a hospital, allowing users to understand each step of the procedure without involving real patients.

---

## 🎯 Objectives

-  Simulate a virtual hospital environment.
-  Demonstrate the blood sample collection procedure.
-  Provide interactive VR-based learning.
-  Improve understanding of healthcare procedures.
-  Explore immersive technologies in medical education.
